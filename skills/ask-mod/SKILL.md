# 问模组

Minecraft 没有 Mojang 官方的模组百科。权威来源按这个顺序用：

1. **MC百科**（https://www.mcmod.cn / https://search.mcmod.cn）：中文社区事实标准的模组词条。
2. **Modrinth**（https://modrinth.com，公开 Search API）：项目页、作者、下载。
3. **Modded Minecraft Wiki**（https://moddedmc.wiki）：Sinytra 从 GitHub / Modrinth / CurseForge 抽的模组文档，作补充链接。不要用 Fandom。

步骤：

1. 用 `lookup_mod_wiki` 查词（如 JEI、机械动力）。
2. 用 MC百科摘要回答，附 mcmod 词条；有 Modrinth 页再附官方项目链接。
3. 查不到就直说，不要编。
4. 不要写 `projects/`，不要改播放器。原版方块/机制请改走 `ask-mc`。
